# Sol Cabinet v1.5.5-lab.2

状态：LAB（实验态，不是正式发布）

本版本继承 [`v1.5.5-lab.1.md`](v1.5.5-lab.1.md) 的全部实验覆盖，新增并固化 Stable／LAB 并行 Runtime 的部署身份机制。

## 本版本新增覆盖

- GitHub `main` 仍是唯一 Stable 来源；`lab/v1.5.5-lab.2` 是候选来源，二者不自动互相晋升。
- 一个本机 Runtime 同一时刻只有一个活动通道，但外部状态凭证必须记录 `channel` 与 `source_ref`，明确当前运行的是 `stable/main` 还是 `lab/lab/v...`。
- 旧的 v1 状态凭证继续只按 Stable 解释，保证 v1.5.4 回滚兼容；新部署状态使用 v2 结构。
- LAB 版本使用 `1.5.5-lab.N`，捕获状态时必须显式传入 LAB source ref；不能把候选版本伪装成 Stable。
- 安装核验必须同时绑定目标 commit 和目标 channel；`SYNCED` 只证明当前 Runtime 与指定通道、commit 和摘要一致。

## 停止条件

任何 channel、source ref、VERSION、系统摘要或安装结构不一致，都按 `DRIFTED`、`STALE` 或 `UNTRACKED` 处理，不继续覆盖。真实工作验证仍以 v1.5.4 为质量兜底，LAB 不自动进入正式发布链。
