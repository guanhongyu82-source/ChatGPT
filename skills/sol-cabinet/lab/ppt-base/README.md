# PPT 模块化数字基座（v1.5.5-lab.1）

本目录是 Sol Cabinet v1.5.5-lab.1 的 PPT 设计实验数据层，不是第二个 Skill。

- `runtime-index.json`：日常 PPT 设计只加载这一份；包含 28 个一级版式族、二级变体、20 个组合元件、候选映射和正式领导汇报默认密度。
- `evidence-map.json`：仅在版式冲突、深度设计或来源追溯时按需读取；保存样片来源指纹和一级版式族代表页。
- 373 页完整页级索引不进入 Runtime，也不复制进本 LAB 主加载，以避免让普通 PPT 任务变重。

核心原则：品牌层强继承；版式层柔性调用；页面结构由内容驱动。用户模板提供视觉语言，不决定成品页数和逐页结构。

样片提取的色值、字体与 Logo 位置均是观测结果，不等同正式招商港口品牌规范。
