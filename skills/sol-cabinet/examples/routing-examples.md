# 匿名路由示例

| 任务 | 决策 | 不增加的动作 |
|---|---|---|
| 一句话改标点 | T1，主代理直接完成 | 不开代理、联网或建文件 |
| Word 指定段末补一句，无新事实或风险 | `bounded_edit=true`，通常T1-T2；先原稿归档，精准修改并验证影响范围 | 不重写整稿，不自动升T4或加载六岗 |
| 正式 Word 整稿或多源报告 | 按材料、事实与交付判级，必要独立审核；可独立材料先并行提取 | 不按等级预设执行人数，起草不抢跑依据 |
| 台账拆并 | 按语义事项与来源映射，合计守恒，未给主责或权重不推定 | 不按标点拆行，不自动给未知值 |
| 敏感内部材料 | 保密提示、范围锁定、必要独立复核；隔离不足时BLOCKED | 不联网、传连接器或写长期记忆 |
| 多附件正式报告与附表 | 独立工作面和收益决定额外执行代理，事实与遗漏分别核验 | 不用“12个实例”定义完成 |
| 阶段性核心维护 | 只改已授权核心，候选与落地分别检查，交付后停止 | 不清外围、改全局模型或自动进入下一阶段 |

模型策略描述能力需求，不能把继承当前会话误写成已经自动切换档位。上述示例是路由验收边界，不是固定人数或工序套餐。
