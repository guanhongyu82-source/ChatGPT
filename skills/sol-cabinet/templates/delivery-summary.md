# 完工小结

文件型任务在成功交付前必须给用户一段简洁完工小结；纯分析任务也应有明确结果收口。不得只回复“已完成”。

## 必填内容

- **完成内容**：本次实际完成了什么。
- **实际成品**：逐项列出最终交付物；文件任务写真实文件名与路径／可下载位置。
- **目标目录核对**：该进的成品是否全部在位；最终目录是否仅含允许交付的成品和用户明确附件。
- **原稿保护**：已完成／不适用／未完成；有原稿时说明原件未覆盖状态。
- **关键核验**：内容、结构、公式、哈希、可打开性、视觉核验等本次真正执行过的项目；未执行的不得写成已通过。
- **未完成／限制**：无则写“无”；有则明确 PARTIAL／BLOCKED 及最小影响。
- **总耗时**：有可靠起止时间则写真实墙钟；没有可靠时间则明确“无法精确核实总耗时”，不编造秒数。
- **失误与处置**：仅本次有实质失误时写一句，否则省略。

## 文件型任务附加对账

成功前必须确认：

1. 预期成品清单与实际成品逐项对应；
2. 用户指定格式、版本、命名和目标文件夹均满足；
3. `outputs/` 或用户指定最终目录没有混入过程稿、审核 JSON、日志、测试件、缓存、锁文件、临时转换件或其他无关产物；
4. `00_原稿/`、`work/`、`outputs/` 或用户指定目录各自内容符合职责；
5. 如果宿主限制导致无法实际整理目录，必须明确说明未完成，不能虚称归档完成。

## 兼容字段

需要更详细交接时可按下列字段展开，但不为形式机械堆字：

- 输出路径：
- 改动范围：
- 原稿目录：
- 原稿数量：
- 原稿清单：
- SHA-256 核验：通过／失败／未执行／不适用
- 原文件未覆盖：是／未验证／不适用
- 视觉渲染核验：已完成／未完成／不适用
- 归档与临时留存：实际状态；延后原因／必要留存

## 本次自我进化

非瞬时任务的完工小结末尾默认附一个简短“本次自我进化”区块，只报告与本次任务直接相关且已经发生的状态，不展示内部流水账。固定使用以下四项，能一句说清的不扩写：

- **沉淀**：本次形成或验证了什么可复用的执行认识；没有新增时写“复用现有机制，无新增规则缺口”，不得把用户业务正文、姓名、单位、文件名或敏感内容当作沉淀。
- **记录**：真实说明是否形成 INC/EV、Direct Policy Change 维护计划、候选或其他既有记录；没有持久记录时写“无”。只显示必要的记录类型／ID，不默认展开内部 evidence 路径、hash 或日志。
- **进化状态**：使用“未触发优化 / 已记录观察 / 已建立维护计划 / 候选准备中 / CANDIDATE READY / 已正式晋升”等真实状态；不得把计划、记录、候选或测试通过写成 Stable/EVO。
- **后续路径**：只写下一步实际需要的动作，例如继续观察、等待同类第二个独立任务、进入最小候选、等待用户裁决／FINAL；没有后续动作时写“继续复用现有机制”。

进化观察、incident 记录、阈值计数、维护计划建立和权限范围内的候选准备默认**静默执行**，不在任务过程中另发“已记录／已建计划／正在进化”等过程通知；统一在完工小结的本区块报告。只有出现 `BLOCKED`、必须由用户选择方案／边界，或候选已到需要用户最终发布授权的节点时，才允许在任务中途主动提示。静默不等于后台持续运行，也不授权跨任务继续施工。

仅本次正式晋升时，在“进化状态”或其后附：`EVO-YYYYMMDD-HHMMSS｜改进内容｜质量↑ / 速度↑｜回归通过`。只写有证据的提升；没有正式 EVO 不显示该格式。

维护提醒仅使用本任务已知且可核实的既有事故／候选状态，在现有小结按需附一行；不新增扫描、日志块、流程或定时任务。满足以下任一条件才显示：

- high-impact 真实事故仍待处理（现有字段 `impact=high`）。
- 同类真实事故已达到既定重复阈值（两个独立任务），且已形成待处理候选；只有 hits 达标不显示。
- 存在 `pending-approval` 候选，或已形成候选因 Work→本机写回限制等待 Codex 维护。

按待办理事项去重计数，同一事故及其候选只计一项；已晋升、已关闭或已撤销事项不计入。最高级别沿用已有权限判断（approve 高于 auto）；尚无判断写“待判定”，不得为提醒自行授予或推断权限。格式：`维护：待进化 N 项｜最高级别：approve / auto / 待判定｜建议：交给 Codex`，级别只显示实际适用值。

未满足条件不显示任何维护提醒，也不显示“0 项”；普通 observation、首次低影响事故、hits 日志和内部分析均不另行展示。已正式晋升的事项按上述 EVO 规则显示；若另有符合条件的待办，可同时保留一行维护提醒。提醒只表示需要交棒，不触发维护、批准或晋升。
